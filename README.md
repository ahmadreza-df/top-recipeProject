# top-recipeProject

## Project description
This project is a basic recipe website built as part of The Odin Project curriculum.
It demonstrates the foundational skills of HTML, including linking pages, adding images, and structuring content.

## Skills demonstrated
- Basic HTML document structure (AKA boilerplate)
- Semantic HTML tags (Headings, paragraphs, lists)
- Creating absolute and relative links
- Adding images to a website
- Using Git and GitHub for version control
